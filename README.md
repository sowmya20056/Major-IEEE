Privacy Preserving Auditing in Cloud Environment
Project Overview

This project focuses on providing secure and privacy-preserving auditing for data stored in cloud environments. It ensures that users can verify the integrity of their data without exposing sensitive information to third-party auditors

Objectives

Ensure data privacy in cloud storage
Provide secure auditing mechanism
Prevent unauthorized access
Maintain data integrity without data leakage
Features

Secure cloud data storage
Privacy-preserving public auditing
Data integrity verification
AES encryption for data protection
Password hashing for authentication
Technology Stack
Programming Language: Python
Cloud Platform: AWS / Firebase
Database: MySQL / MongoDB
Cryptography: OpenSSL / PyCryptodome
Tools: Arduino IDE (if hardware used), Git & GitHub
Methodology
User uploads data to cloud
Data is encrypted using AES algorithm
Metadata is generated for auditing
Third-party auditor verifies integrity
Data privacy is preserved during auditing
